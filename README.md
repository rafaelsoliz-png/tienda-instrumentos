# Tienda de Instrumentos - Sistema de Inventario

Aplicación web desarrollada con Python, Flask y MongoDB para la gestión del inventario de una tienda de instrumentos musicales. Este proyecto implementa un CRUD completo, manejo de imágenes y un sistema de filtrado avanzado.

## Características Principales

* **CRUD Completo:** Creación, lectura, actualización y eliminación de productos (instrumentos).
* **Filtros Avanzados:** Búsqueda por nombre, filtrado por categoría y rango de precios de forma combinada.
* **Manejo de Imágenes:** Soporte para URLs de imágenes o carga de archivos locales con asignación de imagen por defecto.
* **Interfaz Responsiva:** Diseño limpio y funcional utilizando Bootstrap 5 y Jinja2.

## Tecnologías Utilizadas

* **Backend:** Python 3, Flask
* **Base de Datos:** MongoDB (PyMongo)
* **Frontend:** HTML5, Bootstrap 5, Jinja2
